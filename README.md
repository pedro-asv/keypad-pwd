# Porta Digital com Senha (Arduino)

Simulação no Tinkercad de uma fechadura eletrônica: o usuário digita uma
senha em um teclado matricial (keypad) e, se estiver correta, um servo
motor destranca a porta. Senha errada 3 vezes bloqueia o sistema.

![Porta Digital](https://github.com/MasterySuporte/keypad-pwd/assets/84245534/a4aeff36-5fff-462b-a552-5639b3c3552c)

## Tecnologias

- C/C++ (Arduino)
- Bibliotecas: `Keypad`, `LiquidCrystal`, `Servo`
- Simulação em [Tinkercad Circuits](https://www.tinkercad.com/things/hbSuBDawpoy-porta-arduino)

## Componentes

- Teclado matricial 4x4
- Display LCD 16x2
- Servo motor (trava da porta)

## Como rodar

Abra o link do Tinkercad acima para simular direto no navegador, sem
precisar de hardware físico.
